# Where the trees' pictures come from

All the trees' pictures (bark, leaves, needles) are made by `textures.py` from these photo sets. Every set is
**CC0 1.0 (public domain)**: free to use, change and ship, and no credit is required. We credit the authors anyway.
The downloads are not in Git (build/tree-sources/); `textures.py` names each set it reads.
